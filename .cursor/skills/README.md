# .cursor/skills

## Purpose
This folder stores project-scoped Cursor skills that encode reusable guidance for this repository.

## Component Registry
- `unity-breakbrick-standards/`: Skill package that defines Unity and architecture guardrails for Break Brick.

## Communication
- Skills in this folder are discovered by Cursor when user prompts match each skill's trigger terms.
- Skills influence agent behavior by providing structured instructions and checklists for planning and implementation.
- Outputs are safer, more consistent code and decisions aligned with project conventions (DI, performance, and data-driven design).
