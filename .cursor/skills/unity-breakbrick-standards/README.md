# unity-breakbrick-standards

## Purpose
This folder contains a Cursor skill that enforces Unity coding standards for Break Brick, with emphasis on VContainer DI, performance, and modular architecture.

## Component Registry
- `SKILL.md`: Primary instructions, trigger scenarios, and enforcement checklist for the agent.

## Communication
- The skill is applied when prompts involve Unity scripting, architecture decisions, systems design, or optimization in this project.
- It guides the agent to produce plans first, justify design choices, and maintain decoupled, data-driven implementations.
- Expected side effects are improved maintainability, lower runtime allocations, and consistent DI registration practices.
